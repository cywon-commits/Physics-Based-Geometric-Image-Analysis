# PBGIA 새 2D 계산: 비정규화 비분리형 미분 커널 최적화

실행 기반: 사용자 제공 `TextureFilterTrain5.ipynb`의 5×5 대칭 커널과 L-BFGS-B 학습 원리. 수치는 **이번 대화에서 직접 실행한 새로운 2D 파일럿**으로, 기존 Codex의 독립 테스트 점수를 재사용하지 않았다.

## 핵심 결과

한 자화장 생성 미분 커널에 6개의 자유계수를 두고, 고정 4차 중심차분을 정확히 포함시켰다. 교환 연산자는 모든 모델에서 최근접 합(`K_J = NN`, 합 4)으로 **고정**했으며 생성 미분 커널의 합계나 1차 모멘트를 정규화하지 않았다. 관측 연산자도 고정 4차 중심차분으로 통일했다. `N=10`, `J=D=1`, `h=2`, 주기 경계, EDT/tanh 초기장(width=2.3).

| 조건 | 생성 커널 | 둘레 MARE (%) | 방향 MAE (도) |
|:--|:--|--:|--:|
| 신규 clean test | 고정 4차 | 1.207 | 1.188 |
| 신규 clean test | 원본 노트북 5×5 커널 이식 | 8.733 | 0.561 |
| 신규 clean test | 학습 5×5 | **0.573** | **0.537** |
| 신규 1% salt-pepper test | 고정 4차 | **1.228** | 1.167 |
| 신규 1% salt-pepper test | 학습 5×5 | 1.883 | **0.687** |

깨끗한 영상에서 학습 커널의 상대 개선은 둘레 MARE 52.5%, 방향 MAE 54.8%이다. 이는 모든 형상·3D·실제 영상에서의 우월성을 증명하는 것이 아니다. 1% 잡음에서 둘레 측정은 오히려 악화됐다. 학습에는 잡음 영상을 넣지 않았다.

## 최적화와 중첩 관계

커널은 `Kx[dy,dx]`가 x에 대해 홀수, y에 대해 짝수인 완전 비분리형 5×5이며 `Ky=Kx.T`이다. 독립 계수 6개는 `(|dy|=0,1,2) × (dx=1,2)` 순서이다. 부호는 SciPy convolve와 PyTorch correlate 사이 차이를 보정했다. 4차 중심차분은 정확히

`theta_G4 = [2/3, -1/12, 0, 0, 0, 0]`

이다. 원본 노트북 5×5 계수의 이식은

`theta_old = [1, .57063894, .30414468, .33693168, .09205035, .08973684]`

이다. 이는 **원본 알고리즘 전체 재현이 아니다**. 교환 커널은 최근접으로 고정했으며, 원본의 `KJ=Kx²+Ky²`, 이진 초기조건, `h=1`과는 다르다.

모델의 기하학적 적분값 `I=Tr(T)`, `T_ij=Σ_{r,a} (∂_i n_a)(∂_j n_a)`를 계산했다. 둘레 보정계수 `c=L_ref/I_ref`는 **학습 전용 원(r=10.3)**으로 계산했다. 방향은 `T`의 최소 고유방향으로 정의했다. 학습 손실은

`L = mean(((c I - perimeter)/perimeter)^2) + mean(angle_error_rad^2) + 3 mean((std_rotation(I)/mean_rotation(I))^2)`

이다. Dice, IoU, Euler 수, 위상수는 학습에 사용하지 않았다.

학습 36개(원형 6개×회전 6), 검증 32개(4원형×회전 8), 시험 84개(7원형×회전 12). 그룹별 여러 회전은 서로 독립된 관측 단위가 아니다. 실제 독립 시험 원형은 7개이며, 방향을 정의한 원형은 3개이다. 완전히 새 테스트 family는 ring과 분리된 multi이며, rounded_box는 학습에는 없지만 검증에는 포함된다.

최적화는 `PyTorch` 자동미분을 통한 정확한 역전파 + `SciPy L-BFGS-B`로 수행했다. 4차 시작과 원본 5×5 시작의 두 차례 실행, 각각 16회 반복 상한·18회 목적함수/기울기 평가. 두 최적화 모두 반복횟수 상한으로 종료했으므로 수렴 인증이 아니다.

| 초기값 | train objective | validation objective |
|---|---:|---:|
| 고정 4차(무학습) | 0.001278 | 0.002310 |
| 원본 5×5(무학습) | — | 0.001721 |
| 고정 4차에서 학습 | 0.000234 | 0.000405 |
| 원본 5×5에서 학습 | 0.000236 | **0.000398** |

검증 손실만으로 최종 후보를 선택했고, 선택 후 테스트를 평가했다. 동일 관측자를 고정했으므로 개선은 *관측 커널 재학습* 효과가 아니다. 초기값 두 곳에서 유사한 결과가 나왔으나 국소해 또는 전역최적 보장은 없다.

검증 선택 최종 6계수:

`[0.9977219010, 0.2627368384, 0.6181480763, -0.0537138957, 0.2655010729, -0.3789518109]`

이 커널의 x 방향 선형 응답(`Σ dx Kx`)은 약 3.12이고, 4차 중심차분의 1.00과 다르다. **미분 커널을 정규화하지 않았기 때문에 `D`의 실효 세기와 고주파 응답도 함께 변한 것**이며, 잡음 감도 악화의 원인 후보이다. 이는 인과적으로 입증된 설명은 아니다.

## 형상별 clean 테스트 둘레 MARE(%)

| 형태 | 고정 4차 | 학습 5×5 |
|---|---:|---:|
| 원 2개 | 0.639 | 0.561 |
| 타원 | 1.286 | 0.384 |
| 스타디움 | 1.965 | 0.677 |
| 둥근 사각형 | 2.430 | 0.633 |
| 링 | 0.793 | 0.364 |
| 분리된 다중 원 | **0.693** | 0.831 |

원의 집계값은 두 반지름 원형에 대한 평균이다. 개별 원 중 큰 원은 학습 커널이 0.088 퍼센트포인트 더 나빴다. 7개 독립 원형 가운데 5개는 개선, 2개는 악화. 독립 원형 단위 paired bootstrap(10,000회)의 둘레 MARE 차이(학습−4차)는 평균 -0.634 퍼센트포인트, 설명적 95% 구간 [-1.162,-0.161]; 방향은 3원형뿐이므로 불확실성 추정이 매우 제한적이다. 일반적 유의성 증명으로 해석하지 않는다.

## 남은 한계와 다음 실험

- **2D 파일럿만 수행**. 3D 커널 최적화나 실제 영상 일반화는 아직 실시하지 않음.
- 학습 원형 6개, 검증 4개, 시험 7개로 적다. 방향 시험 독립 원형은 3개뿐.
- 손실 가중치와 초기화 폭은 이번 파일럿 설정이며 최적 값이 아니다.
- 미분 커널 선형 응답과 고주파 감도를 따로 제한하지 않았다. 특히 1% salt 잡음에서 정확도가 악화됨.
- 원본 451회전 실험 자체를 재실행한 것이 아니라 **원본 학습 커널을 후보로 사용**했다.
- 이전 Codex 보고서와는 영상 크기, 형상, 관측 head, 교환항이 달라 퍼센트를 직접 대조하면 안 된다.
- 다음 실험: 3D 대칭 비분리 커널, 회전 수 증가, 잡음 포함 학습, 저파수 gain/고주파 Fourier 페널티의 필요성 검토, 미분·교환 공동 학습, 해상도 간 보정계수 전이, 새 잠금 시험 집합.
