# AI provenance

This folder keeps the records of AI tools used in this project, so that the disclosure in the manuscript (Methods, "Use of artificial intelligence tools") can be checked against them. Nothing here is needed to reproduce the results.

| Folder | Content |
|---|---|
| `codex/` | Task descriptions given to OpenAI Codex for the computation scripts of the dynamic-normal and fixed-iteration studies (2026-11-16), the start message, and a critical review written with Codex. The scripts these produced are in `code/` and `fixed_iteration/code/`. |
| `gemini/` | A trial draft produced with Google Gemini as a comparison test (file renamed from `gemini-code-1779942824405 (1).tex`). Later manuscripts were not written from it, and it is unrelated to the current manuscript; it is kept only as a record. |

The dated log of tool use is in [`../AI_USE_LOG.md`](../AI_USE_LOG.md). Commits made with Claude Code carry a `Co-Authored-By: Claude` trailer.
