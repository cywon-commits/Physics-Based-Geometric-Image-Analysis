# Source image rights (new pilot)

Only synthetic images and independently documented CC0 examples appear in manuscript figures. The two images supplied by the user for discussion (rod arrays and a skyline) are **not included**.

- `skimage.data.brick()` — original Bricks25 texture via CC0Textures, CC0; reused with crop/resize/rotation/overlay.
- `skimage.data.retina()` — original *Fundus photograph of normal left eye* by Mikael Häggström (Wikimedia Commons), CC0; reused as gray contrast image with transformations.
- `skimage.data.grass()` — original Grass 01 by linolafett at DeviantArt, licensed CC0 as documented in scikit-image dataset docstring.
- Synthetic strata, synthetic collagen-like fibers, synthetic leaf-vein analog, synthetic textile weave, synthetic wood grain, synthetic building array — original numerical illustrations generated for this study; do not identify them as measured biological/geological scenes.

All source descriptions are based on `scikit-image` dataset source documentation; original source files should be preserved or rechecked before publisher submission. This document does not imply that every CC0 image has physically measured director ground truth.
