# 이번 추가 그림의 출처

- Figure 1 / Figure 3 / Figure 7-3D / Figure 7-2D / 3D volume visualization: 저자 측 코드로 생성한 **synthetic geometric data**. 외부 사진 없음.
- Brick deskew: `scikit-image` 공개 예제 `skimage.data.brick()`, CC0 공용 데이터 출처. 코드에서 회전/교정 및 잘라내기 수행.
- Collagen-like, strata, leaf-vein analog: 실제 생체/지질 시료가 아닌 synthetic patterns; 출처는 재현 스크립트.
- User-provided gold nanoparticle montage: 원본 사용 권리 확인 불가. 내부 파일럿으로만 통계 처리, 원본 이미지를 원고의 그림 또는 ZIP에 포함하지 않음. 정확한 개수 판단은 수작업 라벨과 분할 검증이 필요.
- 실제 3D micro-CT 원본: 이 패키지에 없음. 데이터 제공 여부·라이선스·파일 입수 상태를 반드시 별도로 확인.
