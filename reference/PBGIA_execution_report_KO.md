# PBGIA 수치연구 실행 보고서 — 2026-11-16

## 요약

기존의 2D 스태디움·그레이스케일 연구와 3D voxel 검증을 재분석하고, 3D를 **이진 마스크만 사용하는 초기화**로 재실행해 이완 길이를 500회까지 연장했다. 이번에는 새로운 고차 커널을 학습하지 않았다. 다중 목적의 기하학 측정에서 무엇이 안정적이며 무엇이 아직 실패하는지 확인하는 데 집중했다.

### 확인된 결과

| 항목 | 관측 결과 | 해석상 주의 |
|---|---|---|
| 2D 스태디움 R=20, 36 회전각 | 에너지 CV=0.1106%, 범위=0.3322% (평균 에너지로 정규화) | 4-neighbor 이완 모델의 **회전 안정성**이지 다른 형태 일반화는 아님 |

| 같은 데이터의 Crofton CV | 0.8651% | 비교법/보정법을 명시해야 함 |
| 그레이스케일 level-set 독립 테스트 12개 | 자기 에너지 둘레 MAE 0.298%, Crofton 1.719% | 합성 soft-edge 스태디움만 평가; 다른 기하형상 검증 필요 |

### 분석 1. 2D: 고정 reference로 회전 불변성 측정

이미 계산된 36개 회전 데이터를 이용해, 0°의 스태디움을 단 하나의 reference로 고정했다. 다른 35개 각도에는 `L_est(θ)=L_true(0) E(θ)/E(0)`을 적용했다. 에너지 평균으로 모든 각도를 다시 맞추지 않았다. 모든 각도의 길이는 이론적으로 동일하므로 각도 CV가 주요 척도다.

`R=20`, `A=4.5`, `h=1`, `D=0.02`, 128×128 grid, 4-neighbor 교환 이완. 에너지 CV 약 0.1106%, 에너지 범위/평균 0.3322%; 4방향 Crofton CV 약 0.8651%. 이 결과는 **rotation invariance**에 관해서는 긍정적이다. 다만 방향이 다른 동일한 스태디움으로 교정 계수를 옮기는 것은 'shape transfer'가 아니다.

### 분석 2. grayscale: 이전 실험의 holdout 검사

`R=11,15`, threshold=0.35,0.5,0.65인 soft-edge stadium 18 case를 다시 검토했다. 각각 6개 training threshold case와 12개 holdout case로 나뉜다. 이전 실험에서는 학습셋에서 공통 스케일을 least-squares로 선택했다. 테스트 MAE: 자기 에너지 둘레 0.298%, Crofton 1.719%; 방향 MAE: 자기 텐서 0.218°, PCA 0.174°. 서로 다른 threshold는 같은 underlying stadium에서 나온 상관 표본이다. 따라서 실질 독립 geometry 수는 작은 편이며, 독립 영상 레벨의 반복 시험이 필요하다.

### 분석 3. 3D: 원본 연속 기하 signed distance 사용 금지

이전의 3D 예비 코드에서는 분석 대상 마스크를 만들 때 사용한 **정확한 해석적 signed distance**를 그대로 `n` 초기화에 이용했다. 이는 실제 binary voxel에는 주어지지 않는 정보이므로 벤치마크에서 불공정하다. 이번 재계산은 `distance_transform_edt(mask)-distance_transform_edt(~mask)`만 사용하도록 바꾸었다. 실제 목표는 binary-only geometric inference이다.

3D 모델: `n=(v_x,v_y,v_z,s)` with `|n|=1`, `E=A sum_bonds |n_i-n_j|² + h sum_i(1-f_i s_i) − ε sum_i v_i·∇f_i`. 56³ voxel, `A=3`, `h=1`, `ε=0.16`, 6-neighbor, 고정 `dt=0.022`. 구 R=9 (centered)를 단일 reference로 두고 **각 iteration에서 동일 reference energy**로 나누어 비교했다.

| 도형 | 250회 상대오차 | 500회 상대오차 | 500회 residual RMS |
|---|---:|---:|---:|
| 중심 구 R=9 (기준) | 0% | 0% | 0.000027 |
| 이동 구 R=9 | −1.145% | −1.145% | 0.000028 |
| 이동 구 R=12 | +1.206% | +1.208% | 0.000015 |
| 수평 캡슐 R=7,L=16 | −1.298% | −1.678% | 0.002066 |
| 3차원 회전 캡슐 R=7,L=16 | −2.292% | −2.676% | 0.002039 |
| 토러스 R=12,r=4.5 | +4.664% | **−11.916%** | 0.023706 |

구의 에너지는 250→500회에 거의 불변이었다. 캡슐은 여전히 완화 중이며, 토러스는 **오히려 잔차가 증가**하며 에너지가 큰 폭으로 내려갔다. 이 현상의 원인이 (i) topology-preserving anchoring 실패, (ii) local minimum 사이의 진입, (iii) finite-time dynamics 또는 (iv) 수치 구현에 있는지 별도 진단이 필요하다. 토러스에서는 500회 결과조차 최종 최소에너지라고 선언할 수 없다.

### 주요 모델 위험과 해석 한계

1. **이완 안정성:** 안정적인 모양에서는 표면적을 추정하지만 일부 비단순 연결 도형에서 상이한 위상 섹터·계면 형태로 변화한다. 에너지만 최저로 만든다고 원하는 입력 경계가 보존된다는 보장이 없다.
2. **설명 변수 유출:** 생성한 연속 도형의 `d(x)`를 솔버에 넘겨서는 안 된다. 본 재계산은 binary-only로 수정했다.
3. **통계적 일반화:** 현재 3D 독립 도형 수는 매우 작다. 1–2% 결과를 범용 정확도라고 주장할 수 없다.
4. **공정성:** 기존 marching cubes는 이진 데이터와 threshold/보간 설정에 따라 값이 달라진다. 동일 calibration budget을 제공하고 노출 면적·Crofton·고차법을 나란히 보고해야 한다.
5. **위상 전하:** 이미 기존 계산에서 2D solid-angle skyrmion charge가 안정적이라는 예비 결과가 있다. 이는 geometry accuracy의 대체 지표가 아니다. 3D finite difference degree의 정수 편차도 method-dependent하다.
6. **선행연구:** diffuse-interface perimeter, phase-field segmentation, coarea, vectorial TV는 선행되어 있다. 연구의 차별성은 실험으로 보여야 한다.

### 진행 권고 및 최우선 신규 계산

**P0:** 3D torus의 붕괴 원인을 분석한다. iteration별 `E_ex`, `E_field`, `E_SB`, `Q3`, interface position, 분포의 경계 `s`을 저장하고 여러 `ε`와 초기 시드로 반복한다. 다중 에너지 최소값 중 **영상에 충실한 안정적 상태**를 정의할 필요가 있다.

**P1:** 공정한 2D/3D holdout benchmark를 최소 100–300 synthetic shapes로 확장하고, 오차 신뢰구간을 보고한다. `circle/sphere` 하나의 정규화와 전이 성능을 구분한다.

**P2:** 2D 9점 및 3D 등방 다점 커널의 기본 모델과 소수 파라미터의 optimized kernel만 비교한다. 수치 최적화 자체가 논문의 중심이 되지 않도록 한다.

**P3:** 2D RGB/3D grayscale level-set에서 동일한 복원 원리가 유지되는지 테스트한다. 채널별 클래스 마스크의 경계 중복은 계량한다.

## 추가 진단: 토러스에서 나타나는 위상·계면 불안정성 (700회)

단순한 미수렴 가능성을 살펴보기 위해, 토러스 하나에 대해 동일한 binary-only 초기화로 700회까지 수행하고 각 시점의 교환/고정장/대칭 깨짐 에너지, projected-gradient RMS, 입력 마스크와 `sign(s)`의 일치율, finite-difference `Q3`를 기록했다 (`pbgia_torus_diagnostic.csv`).

- 250회: E≈11529, 입력 이진 마스크와 `s>0` 일치율≈98.79%, Q3_fd≈0.078.
- 450회: E≈9935, 일치율≈98.08%, Q3_fd≈0.892.
- 500회: E≈9702, 일치율≈97.73%, Q3_fd≈0.861.
- 650회: E≈9431, 일치율≈97.27%, Q3_fd≈0.002.
- 700회: E≈9400, 일치율≈97.27%, Q3_fd≈0.001.

`Q3_fd`는 단순한 중심차분 적분이며 정수 정확도나 위상 전이의 엄밀한 증거로 해석하지 않는다. 다만 긴 이완 중 위상 밀도 및 계면 배치가 크게 재편되고 있다는 명백한 경고이다. 특히 토러스는 지표가 안정화되기 전에 에너지 기반 면적 추정이 크게 변한다. **'최소에너지=원 영상의 안정적인 표면'이라는 가정을 본 연구의 검증 대상**으로 명확히 설정해야 한다. 형태 fidelity constraint, anchoring strength 조절, 최종장과 초기 마스크 사이 consistency를 포함한 수렴 진단이 요구된다.
